Skyrocket

Summer 2026

202613 / 31

The presence accuracy saga

“Busy” on PlayStation broke everything. Fixing it took a heist.

  • The problem: people show “busy” while actually playing → automations go wonky.
  • Safety first: a separate bot PSN account takes all the API risk — ban the bot, not the person.
  • The heist: 7 clan members paste their NPSSO tokens into the platform after a trust conversation.
  • Result: mid. The API still returns whatever status the user set — so activity data became the workaround.
  • It detects when a game begins… but never when it ends.
202614 / 31

Send as yourself

TheMooseCompany was “mute moose” — and accidentally invented a feature.

  • A manual message bar was added for one-off messages.
  • Moose, restricted from talking aloud so as not to disturb family, used it more than native PSN messaging — it was quicker.
  • The catch: messages sent as the bot.
  • The fix: with everyone’s NPSSO already in hand, send-as-yourself was built.

202618 / 31

The clip pipeline

Clip it on PlayStation → it’s in WhatsApp before you put the controller down.

  • A PSN group clip gets auto-downloaded and forwarded to WhatsApp, Discord, AND Mattermost.
  • WhatsApp was the hard one — cracked with Baileys, the open-source WhatsApp Web library using QR linked-device pairing (no official API).
  • The spark: Soup’s brother once demoed OpenClaw + WhatsApp via linked device — the idea stuck.
  • Result: 1080p clips land in “PROFESSIONAL GOOPERS” instantly.
  • 77 clips captured, with a monthly auto-montage built on the 1st.
FUN FACTOld flow — open PS app → find clip → download → share → hope the console finished uploading. New flow: just play.
